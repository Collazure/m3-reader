| 编号 | 要求 | 验收要点 |

| R02 | 清晰操作文本更新、按模块更新、图片下载等已有功能 | 显示范围、进度、结果和失败原因；网络任务不阻塞阅读 |
| R03 | 支持文本阅读及图片、PDF 查看，包括《大地巡旅》 | GUI 内查看原件；OCR 命中可跳到对应页；TUI 可打开系统查看器 |
| R04 | 查看最近几次更新的具体内容，精确到行 | 直接呈现差异和上下文；点击定位，无需手工翻找；保留旧版删除行 |

| R09 | 文件内 Ctrl+F 和全局文本搜索 | 显示路径、行号或页码与命中片段；结果可直接打开；支持 OCR 文本 |
| R10 | Windows 和 Ubuntu 双端适配 | 两端有可双击的独立 GUI 程序和 CLI 可执行程序；分别验证启动、路径和媒体 |
| R11 | TUI 从 CLI 明确进入 | `m3-reader tui`，CLI 无需手动输入 Python 和脚本名，保留非交互子命令 |
| R12 | Python 脚本等程序与文本、图片、PDF 等资源清晰分开 | 允许调整目录；manifest 和索引可继续跟随资源，不要求逐个抽离 |
| R13 | 持续维护已知信息记录、版本号和更新日志 | 每次实现同步记录已验证事实、问题、版本和用户可见变化 |
| R14 | 可采集与不可采集资料采取不同维护方式 | 按来源及文件区分，界面显示不同操作，见下节 |

## 资料维护方式

| 类型 | 示例 | 维护操作 |
| --- | --- | --- |
| 自动采集资源 | PRTS 主线、支线、干员、活动等文本 | 增量更新、补缺、强制重抓、查看来源和采集历史 |
| 自动采集图片 | terra 中的泰拉记事社微博图文 | 更新说明与索引；单独下载图片，沿用现有默认不自动下载图片的约定 |
| 本地导入资料 | 《大地巡旅》整本 PDF、用户已有参考文本或图片 | 登记来源、导入或重新关联路径、手动替换版本、查看替换历史；排除在采集更新任务之外 |
| 本地派生资料 | PDF 或图片的 OCR、用户校对稿 | 关联原件；OCR 由本地任务生成并记录工具与时间；校对稿独立保存，重新 OCR 不覆盖校对稿 |
| 用户内容 | 更新意见、阅读位置、书签 | 本地保存；采集、导入替换及 OCR 均不能覆盖 |

不能只凭标题判定维护方式。《大地巡旅》整本 PDF 当前作为不可由现有爬虫采集的本地资料；
terra 中几期同名微博图文仍属于可采集来源。记录资源 ID、来源类型、相对路径及关联关系，避免误操作。
